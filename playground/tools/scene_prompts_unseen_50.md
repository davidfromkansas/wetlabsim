# 50 new scene prompts (not used while tuning)

A held-out test set for "Describe a scene", written after the builder was tuned on the 110 prompts.
None of these were used to make fixes. Same tags: **[short]** short and vague · **[detailed]** long and
detailed · **[missing]** asks for things we likely don't have yet. Numbered from 201 so results never
mix with the first set.

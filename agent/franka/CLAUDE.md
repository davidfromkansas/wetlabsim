This folder is your workspace for operating a lab robot: a Franka Emika Panda arm with
a Franka Hand gripper, on a lab bench. Work in this folder.

What's here:
- `COMMANDS.md`: the robot's command interface (Python) and the agent tools.
- `SITE.md`: how this robot is installed here: mounting, coordinate frames, tool and
  payload settings, cameras.
- `cameras.json`: the camera calibration.
- `datasheets/`: Franka's own documents for the arm and the hand.
- `robot_model/panda.xml`: a MuJoCo model of the arm and hand (the robot only).

Do the task you were given using only the robot's command interface and the agent tools.
